# SpecTexRent — Аренда спецтехники в Москве

**SpecTexRent** — это высококонверсионный интерактивный лендинг-каталог для аренды строительных экскаваторов с водителем в Москве и Московской области. Проект выполнен в премиальном индустриальном стиле (Industrial Dark Aesthetics) с упором на скорость подачи техники, надежность автопарка и прозрачные юридические условия (работа с НДС 20%).

## ⚡ Ключевой функционал

1. **Live Fleet Dashboard (Интерактивная карта)**:
   - Имитация GPS-отслеживания флота техники в реальном времени (мерцающие индикаторы на сетке дорог).
   - Динамический счетчик доступной техники на линии («Свободно сегодня»), обновляющийся с легкой естественной флуктуацией.
2. **Интерактивный фильтр каталога**:
   - Быстрое переключение категорий машин (гусеничные, колесные, погрузчики, мини).
   - Фильтрация по характеристикам (объем ковша, вес машины) и мгновенный показ только свободных единиц.
   - **3D-эффект наклона (Tilt Card)**: карточки техники интерактивно наклоняются вслед за курсором мыши, создавая ощущение глубины.
3. **Пошаговый калькулятор сметы (Quiz)**:
   - **Шаг 1**: Выбор базовой модели.
   - **Шаг 2**: Ползунок смен с автоматическим расчетом скидок за объем (10% от 5 смен, 20% от 15 смен).
   - **Шаг 3**: Интерактивный расчет стоимости логистики тралом в зависимости от удаления от МКАД.
   - **Шаг 4**: Выбор навесного оборудования (гидромолот, узкий ковш) или «холодной аренды» (без водителя и топлива).
   - **Шаг 5**: Фиксация стоимости с возможностью выбора подарка к договору.
   - Правый сайдбар обновляет детальную смету и итоговую стоимость в реальном времени.
4. **Обратный звонок за 59 секунд**:
   - При заказе обратного звонка запускается визуальный таймер обратного отсчета с автоподключением менеджера.
5. **Тестовая панель интеграции с Telegram**:
   - В нижнем левом углу страницы встроена скрытая админ-панель.
   - Введите `Bot Token` и `Chat ID`, чтобы моментально перенаправить заявки и расчеты с калькулятора в ваш Telegram-канал или личный чат в формате красиво сверстанных HTML-сообщений.

## 🛠️ Технологический стек

Лендинг разработан как сверхбыстрое Single Page Application без тяжелых сторонних фреймворков:
- **Разметка**: Семантический HTML5 с оптимизированными SEO-тегами.
- **Стили**: Ванильный CSS3 с использованием CSS Custom Properties (переменных), Flexbox/Grid-сеток, эффектов `backdrop-filter` (glassmorphism) и аппаратных GPU-анимаций.
- **Интерактивность**: Чистый ES6+ Javascript (Vanilla JS).
- **Медиа**: Профессиональные фотореалистичные рендеры спецтехники, сгенерированные искусственным интеллектом.

## 🚀 Как запустить локально

Поскольку проект написан на чистом стеке (HTML/CSS/JS), для локального запуска не требуется сборка:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/rexDeus92/SpecTexRent.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd SpecTexRent
   ```
3. Откройте файл `index.html` в любом браузере (или воспользуйтесь расширением Live Server в VS Code).

## 💬 Настройка отправки лидов в Telegram

Чтобы настроить отправку заявок на ваш канал/чат:
1. Создайте бота в Telegram через [@BotFather](https://t.me/BotFather) и скопируйте его `Token`.
2. Добавьте бота в чат или канал и получите `Chat ID` (например, с помощью бота [@userinfobot](https://t.me/userinfobot) или [@ShowJsonBot](https://t.me/ShowJsonBot)).
3. Откройте лендинг, нажмите на шестеренку в левом нижнем углу экрана, введите данные и нажмите **«Сохранить»** (настройки сохраняются в вашем браузере через `localStorage`).
4. Заполните любую форму на сайте — заявка моментально придет в ваш Telegram!
